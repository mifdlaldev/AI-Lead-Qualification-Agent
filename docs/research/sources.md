# Phase 1 Source Registry

**Research cut-off:** 2026-07-14

This registry records sources used to inform Phase 1. Source types are separated so that research evidence is not confused with marketplace observations or project inference.

## S1 — Large-scale n8n ecosystem study
**Title:** Characterizing Large Language Model Agentic Workflows: A Study on N8n Ecosystem  
**Authors:** Yutian Tang, Yuming Zhou, Huaming Chen  
**Published:** 2026-06-27  
**URL:** https://arxiv.org/abs/2606.29116  
**Use in project:** High-confidence evidence about the structure and reliability characteristics of 6,000+ public n8n LLM workflows.  
**Key supported claims:** real-world workflows combine LLMs with broader automation structures; explicit reliability mechanisms are relatively uncommon.  
**Limitation:** this is ecosystem evidence, not a freelance buyer-demand census.

## S2 — Agentic workflow injection research
**Title:** Comment and Control: Hijacking Agentic Workflows via Context-Grounded Evolution  
**Published:** 2026-05-11  
**URL:** https://arxiv.org/abs/2605.11229  
**Use in project:** Security context for treating externally supplied text as untrusted input and limiting agent/tool authority.  
**Limitation:** security research does not prove market demand.

## S3 — Authenticated workflow security research
**Title:** Authenticated Workflows: A Systems Approach to Protecting Agentic AI  
**Published:** 2026-02-11  
**URL:** https://arxiv.org/abs/2602.10465  
**Use in project:** Supporting context for thinking about trust boundaries across prompts, tools, data, and context.  
**Limitation:** the proposed research system is not automatically adopted as the project architecture.

## Source-handling rules
- Never convert a single job listing into a statement about majority market demand.
- Never convert seller supply into buyer-demand volume.
- Never use ecosystem template counts as revenue evidence.
- Never quote performance numbers from another project as if they were results of this project.
- If a source becomes unavailable, preserve the claim only if another verifiable source supports it; otherwise downgrade or remove the claim.
